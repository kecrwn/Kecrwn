## 🌟 About The Project

This repository hosts a modern, lightweight portfolio website designed for frontend engineers and creative developers. Built from the ground up without heavy external dependencies, it prioritizes blistering performance, accessible markup, and captivating visual details like ambient background glow shaders, micro-interactions, and glassmorphic surfaces.

Whether presenting open-source projects, demonstrating specialized UI proficiencies, or establishing professional client contacts, this portfolio delivers a memorable digital presence.

---

## ✨ Features

- 🌌 **Ambient Glow Aesthetics** — Radial gradient backdrop effects providing depth and modern visual appeal.
- 📱 **Responsive Navigation** — Smooth navigation bar with an interactive mobile slide-out drawer menu.
- 💼 **Featured Project Grid** — Clean showcase cards highlighting project descriptions, tech tags, and direct demo links.
- 🎯 **Skills & Competencies Matrix** — Categorized technical proficiencies across frontend engineering, UI/UX, and tooling.
- 📬 **Contact Call-to-Action** — Streamlined section for getting in touch, project inquiries, and social links.
- ⚡ **Zero-Dependency Core** — Blazing fast load times with pure vanilla HTML, modern CSS, and JavaScript.

## 🚀 Quick Start

### Prerequisites
No build steps or package managers required. Simply use any web browser.

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kecrwn/Kecrwn.git
   cd Kecrwn
   ```

2. **Run locally:**
   - Simply double click `index.html` in your file explorer to open it in your browser, or
   - Launch via a lightweight static server:
     ```bash
     # Using Python 3
     python3 -m http.server 3000

     # Or using Node npx
     npx serve .
     ```
   - Open your browser to `http://localhost:3000`.
